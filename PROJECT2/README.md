# Cloudflare Bypass — Playwright + TypeScript

Strategies for handling Cloudflare bot protection on your **own** staging environment.

---

## Quick Start

```bash
npm install
npm run install:browsers
npm run test:headed   # headed mode is much less likely to be blocked
```

---

## Three Strategies (choose based on your CAPTCHA type)

### Strategy 1 — Auto-resolve JS Challenge ✅ (easiest)
Cloudflare's **"Just a moment… Checking your browser"** screen is a JavaScript
challenge, not an interactive CAPTCHA. It resolves automatically in 5–10 s.
The test simply waits it out while stealth scripts suppress automation signals.

**Works when:** you see the spinning "Just a moment" page.

### Strategy 2 — Stealth Scripts
Injected via `addInitScript`, these patch browser fingerprints that Cloudflare
uses to detect headless automation:
- `navigator.webdriver` → `undefined`
- `navigator.plugins` → fake non-empty list
- `navigator.languages` → `['en-US', 'en']`
- Chrome DevTools protocol properties → removed

Combined with `--disable-blink-features=AutomationControlled` in launch args.

### Strategy 3 — Saved Auth State ✅ (most reliable for CI)
Solve the CAPTCHA once manually, save the resulting cookies, and reuse them
on every subsequent run.

```bash
# Step 1: run in headed mode, solve CAPTCHA manually, state is saved
npm run setup:save-state

# Step 2: all future runs use the saved cookies
npm test
```

The saved file (`auth-state.json`) contains Cloudflare clearance cookies
(`cf_clearance`) that are valid for hours/days depending on your CF settings.

## If You Have an Interactive CAPTCHA (Turnstile / hCaptcha)

An interactive "I'm not a robot" box cannot be bypassed programmatically without
a third-party CAPTCHA-solving service. The cleanest solutions for a staging env:

| Option | How |
|---|---|
| **Whitelist your IP** | Add your CI/test runner IP to Cloudflare → Security → WAF → IP Access Rules |
| **Disable CF for staging** | In CF dashboard, set Security Level to "Essentially Off" for the staging hostname |
| **CF Access bypass header** | Add a secret header in CF WAF rules that skips the challenge when present |
| **Use CF Turnstile test keys** | Cloudflare provides always-pass test site keys for staging: `1x00000000000000000000AA` |

These are the **recommended** approaches for a staging environment — no third-party
services needed.
